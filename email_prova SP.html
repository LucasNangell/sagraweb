Sugerimos que a prova seja conferida com atenção, pois a CGraf não aceitará
reclamações posteriores referentes a serviços que tenham tido a impressão
autorizada.

Informamos que os modelos de papelaria apresentados no sistema “Cotas de
Publicações” estão desatualizados.

Os modelos de Papelaria Oficial atuais, disponíveis para produção, podem ser

consultados no Guia de Papelaria Oficial, disponível em:

https://bityl.co/JVyA

Para autorizar a impressão responda este e-mail, sem alterar o campo Assunto:

- informando "Impressão autorizada conforme Prova"; e

- indicando Nome e Número de Ponto.

Para solicitar alterações responda este e-mail, sem alterar o campo Assunto:

- informando "Solicitamos que sejam feitas as seguintes alterações:" e detalhando as

alterações necessárias; ou

- anexando um novo arquivo para impressão.

IMPORTANTE:

A Prova PDF é sempre enviada para os Serviços da Cota de Papelaria. Para os demais serviços

de impressão (OSs), a Prova PDF é enviada apenas quando não se enquadram num dos

seguintes casos:

- Quando a saída impressa estiver igual ao Original encaminhado pelo solicitante;

- Quando for uma repetição de serviço sem alterações;

- Quando o arquivo original encaminhado pelo solicitante estiver no formato PDF.
